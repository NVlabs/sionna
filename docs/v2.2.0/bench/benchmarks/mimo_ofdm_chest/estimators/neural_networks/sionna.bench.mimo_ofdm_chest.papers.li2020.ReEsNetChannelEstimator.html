ReEsNetChannelEstimator#

Note

  • Estimator constructor defaults mirror the settings used during benchmarking.

  • generate_training_data() defaults mirror the settings used to generate training data.

  • train_model() defaults mirror the settings used to train the model.

class sionna.bench.mimo_ofdm_chest.papers.li2020.ReEsNetChannelEstimator(resource_grid: sionna.phy.ofdm.resource_grid.ResourceGrid, model_states: collections.abc.Sequence[collections.abc.Mapping[str, torch.Tensor]], model_noise_variances: torch.Tensor | None = None, *, err_var_scale: float = 0.234, precision: Literal['single', 'double'] | None = None, device: str | None = None)[source]#

Bases: sionna.phy.ofdm.channel_estimation.BaseChannelEstimator, sionna.phy.ofdm.channel_estimation._PilotGroupMixin

Channel estimator that leverages a residual super-resolution network (ReEsNet) for denoising.

This estimator follows the method proposed in:

  • Lianjun Li, Hao Chen, Hao-Hsuan Chang, and Lingjia Liu. Deep residual learning meets ofdm channel estimation. IEEE Wireless Commun. Lett., 9(5):615–618, 2019.

TL;DR

This estimator models OFDM channel estimation as image super-resolution. The estimator first computes LS estimates at the active pilot resource elements and arranges their real and imaginary parts as a two-channel pilot grid. A trained residual convolutional network then reconstructs the complete frequency-time channel grid directly, without a separate interpolator.

Each receive-antenna and transmit-stream channel is processed as an independent network input. The same trained network weights are shared across these inputs.

Supported System Geometry

  • The active nonzero pilots of every transmit stream form a complete rectangular subcarrier-by-symbol grid.

  • All transmit streams have pilot grids with the same dimensions.

  • The number of effective subcarriers is an integer multiple of the number of active pilot subcarriers.

  • The number of OFDM symbols is an integer multiple of the number of active pilot-bearing OFDM symbols.

  • Every prepared ReEsNet state matches the resulting pilot-grid input shape, full-grid output shape, and network architecture.

UE streams and receive antennas are processed independently, so changing their counts does not change the neural-network dimensions. Assets loaded through the paper’s standard asset loader must nevertheless match the complete recorded system and pilot configuration.

Deviations from the Paper

  • The paper evaluates single-antenna downlink channel estimation. This implementation applies the same network independently to every uplink transmit-stream and receive-antenna channel and shares its weights across them.

  • This implementation derives the input and output dimensions from the supplied Sionna resource grid instead of reusing the paper’s grid geometry.

  • The paper does not specify the transposed convolution’s kernel size, padding, or output padding. This implementation uses kernel_size=stride with zero padding.

  • The paper trains one network across several SNRs. This implementation supports both such a mixed-SNR state and a bank of independently trained SNR-specific tates selected from the input noise variance.

  • The paper does not define detector-facing channel-estimation error variances. This implementation bilinearly upsamples the LS pilot error-variance grid and applies the configurable err_var_scale.

Parameters:

  • resource_grid (ResourceGrid) – Sionna resource grid.

  • model_states (Sequence[Mapping[str, torch.Tensor]]) – Prepared ReEsNet state dictionaries. Each state must contain the tensors for a ReEsNet whose pilot-image input and full-grid output dimensions match resource_grid.

  • model_noise_variances (Optional[torch.Tensor]) – Positive AWGN variance associated with each state, shape [num_models]. These values select SNR-specific states. If None, exactly one mixed-SNR state must be supplied.

  • err_var_scale (float) – Scale applied to the detector-facing variance fallback.

  • precision (Optional[Precision]) – Sionna precision. If None, the global Sionna precision is used.

  • device (Optional[str]) – Torch device. If None, the global Sionna device is used.

Neural Network Training#

Dataset generation, training, and model assets for Li et al. 2020.

sionna.bench.mimo_ofdm_chest.papers.li2020.asset.generate_training_data(resource_grid: sionna.phy.ofdm.resource_grid.ResourceGrid, cfg: sionna.bench.mimo_ofdm_chest.configs.system_config.SystemConfig, *, train_batches: int = 400, train_batch_size: int = 16, validation_batches: int = 16, validation_batch_size: int = 16, training_snr_dbs: list[float] | None = None, paper_style_training: bool = True, seed: int = 42, asset_root: str | pathlib.Path, overwrite: bool = False) → pathlib.Path[source]#

Generate and persist a deterministic ReEsNet training-data bank.

The asset contains clean channel values at the active pilot positions, their pilot powers, and the corresponding full frequency-time channel targets. The same propagated channel realizations are reused across the requested SNR points. During model training, fresh deterministic SNR-specific noise is added to the clean pilot observations in every epoch.

Each complete system-channel realization produces one ReEsNet example for every transmit stream and receive antenna. The numbers of derived neural-network examples are therefore generally larger than the numbers of independently sampled channels. The completed asset is strictly validated before its manifest path is returned.

Parameters:

  • resource_grid (sionna.phy.ofdm.resource_grid.ResourceGrid) – Sionna resource grid whose pilot geometry, pilot values, and full-grid dimensions define the ReEsNet inputs and targets.

  • cfg (sionna.bench.mimo_ofdm_chest.configs.system_config.SystemConfig) – System and channel configuration used to generate the channel realizations.

  • train_batches (int) – Number of independent training-channel batches.

  • train_batch_size (int) – Number of complete system-channel realizations in each training batch. The total number of independently sampled training channels is train_batches * train_batch_size.

  • validation_batches (int) – Number of independent validation-channel batches.

  • validation_batch_size (int) – Number of complete system-channel realizations in each validation batch. The total number of independently sampled validation channels is validation_batches * validation_batch_size.

  • training_snr_dbs (list[float] | None) – SNR points for which the data bank is prepared. The clean pilot grids and full-grid targets are shared across these SNR points. If None, use the SNR grid defined by cfg.

  • paper_style_training (bool) – If True, sample UE velocities uniformly between 0 and 50 km/h as described by Li et al. If False, use the fixed UE velocity defined by cfg.

  • seed (int) – Base random seed for deterministic channel generation. Training and validation use separate deterministic random streams.

  • asset_root (str | pathlib.Path) – Writable external root beneath which the generated payloads and manifest are stored.

  • overwrite (bool) – If True, replace an existing asset with the same identity. If False, raise an error when that asset already exists.

Returns:

Path to the strictly validated training-data manifest.

sionna.bench.mimo_ofdm_chest.papers.li2020.asset.train_model(resource_grid: sionna.phy.ofdm.resource_grid.ResourceGrid, cfg: sionna.bench.mimo_ofdm_chest.configs.system_config.SystemConfig, *, train_batches: int = 400, train_batch_size: int = 16, validation_batches: int = 16, validation_batch_size: int | None = 16, epochs: int = 200, optimizer_batch_size: int = 256, learning_rate: float = 0.000186, patience_epochs: int = 20, relative_min_delta: float = 0.0001, snr_specific_weights: bool = True, training_snr_dbs: list[float] | None = None, paper_style_training: bool = True, seed: int = 42, training_data_manifest: str | pathlib.Path, asset_root: str | pathlib.Path, overwrite: bool = False) → tuple[list[dict[str, torch.Tensor]], torch.Tensor | None, list[pathlib.Path]][source]#

Train and persist an ordered bank of ReEsNet models.

The supplied training-data asset contains fixed clean pilot-channel grids, pilot powers, and full-grid channel targets. For every trained SNR-specific model, deterministic observation noise with the corresponding variance is generated afresh in each training epoch. Training minimizes the paper’s L1 objective using Adam and retains the state with the lowest validation L1 loss.

Every completed model asset is persisted atomically and strictly reloaded before being returned.

Deviations from the Paper

  • The paper trains one ReEsNet across SNRs. This implementation trains one independent model per requested SNR.

  • The paper uses 25,000 channel realizations with a 60/20/20 training/validation/test split, 100 epochs, minibatches of 128, and Adam with learning rate 1e-3. This implementation uses separate deterministic training and validation channel banks, validation-based early stopping, and configurable training budgets and optimizer parameters.

  • The paper samples UE velocity uniformly between 0 and 50 km/h. With paper_style_training=False, this implementation instead uses the velocity specified by cfg so that training and evaluation can use the same channel distribution.

  • The fixed clean channel bank is reused across SNR-specific models and epochs. Fresh deterministic observation noise is generated for every SNR and training epoch. The paper describes generating multiple noisy SNR versions of each channel sample but does not specify this epoch-wise resampling procedure.

  • The paper considers a single-antenna downlink. This implementation derives one training example for every transmit-stream and receive-antenna channel and shares the trained ReEsNet weights across all such examples.

Parameters:

  • resource_grid (sionna.phy.ofdm.resource_grid.ResourceGrid) – Sionna resource grid defining the ReEsNet pilot-grid input dimensions and full-grid output dimensions.

  • cfg (sionna.bench.mimo_ofdm_chest.configs.system_config.SystemConfig) – System and channel configuration defining the channel distribution, SNR grid, numerical precision, and training device.

  • train_batches (int) – Number of independent training-channel batches represented by the supplied training-data asset.

  • train_batch_size (int) – Number of complete system-channel realizations in each training batch. Their product is the number of independently sampled training channels.

  • validation_batches (int) – Number of independent validation-channel batches represented by the supplied training-data asset.

  • validation_batch_size (int | None) – Number of complete system-channel realizations in each validation batch. If None, use train_batch_size.

  • epochs (int) – Maximum number of complete training epochs.

  • optimizer_batch_size (int) – Number of derived ReEsNet examples in each Adam update. Each system-channel realization contributes one example per transmit-stream and receive-antenna pair.

  • learning_rate (float) – Adam learning rate.

  • patience_epochs (int) – Stop after this many epochs without the required validation-loss improvement. Zero disables early stopping.

  • relative_min_delta (float) – Minimum relative reduction in validation L1 loss counted as an improvement.

  • snr_specific_weights (bool) – If True, train one independent model for every requested SNR. The current fixed-data training path requires this to be True.

  • training_snr_dbs (list[float] | None) – SNR values for which models are trained. If None, use the SNR grid defined by cfg.

  • paper_style_training (bool) – Identifies the velocity distribution used to generate the training-data asset. If True, expect UE velocities sampled uniformly between 0 and 50 km/h. If False, expect the fixed UE velocity defined by cfg.

  • seed (int) – Base seed controlling model initialization, training-example ordering, and deterministic observation-noise generation.

  • training_data_manifest (str | pathlib.Path) – Manifest of the compatible fixed ReEsNet training-data asset.

  • asset_root (str | pathlib.Path) – Writable external root beneath which trained model assets are stored.

  • overwrite (bool) – If True, replace model assets with the same identity. If False, raise an error when such an asset already exists.

Returns:

A tuple (model_states, model_noise_variances, manifest_paths). model_states contains the strictly reloaded ReEsNet state dictionaries. model_noise_variances contains the ordered inference noise variances for the SNR-specific model bank. manifest_paths contains the corresponding validated model-manifest paths.

Hyperparameter Tuning#

sionna.bench.mimo_ofdm_chest.papers.li2020.tuning.run_tuning(*, study: str = 'training', n_trials: int | None = None, num_mc_batches: int | None = None, batch_size: int | None = None, output_dir: str | pathlib.Path | None = None, algorithm_output_dir: str | pathlib.Path | None = None, asset_root: str | pathlib.Path, training_data_manifest: str | pathlib.Path | None = None)[source]#

Training Hyperparameter Tuning

The "training" stage minimizes weighted NMSE at -10, -5, 0, 5, and 10 dB. It runs 10 seeded TPE trials. Every trial trains a separate ReEsNet model for each of these five SNRs and evaluates three batches of four channels at each SNR.

All trials reuse the same training-data bank. Every SNR-specific model uses 6,400 training channels and 256 validation channels, at most 200 epochs, patience of 20 epochs, and a relative minimum validation improvement of 1e-4. The best checkpoint is restored. Training uses the paper-style L1 loss and SNR-specific model weights.

Parameter

Search space

learning_rate

logarithmic from 1e-5 through 1e-3

optimizer_batch_size

categorical set {256, 512, 1024, 2048}

The "training-validation" stage retrains and compares the rounded winner with the existing training defaults using 63 batches of four channels at each SNR.

Error-Variance Calibration

The "variance" stage tunes err_var_scale logarithmically from 1e-3 through 1 using 10 TPE trials. Codeword BLER is evaluated at 10 dB over 63 batches of four channels using the frozen canonical model bank.

The "variance-validation" stage compares the rounded winner with the existing scale.

Parameters:

  • study (str) – Stage to execute: "training", "training-validation", "variance", or "variance-validation".

  • n_trials (int | None) – Trial-count override. If None, use 10 for both training tuning and variance calibration. Validation stages do not run Optuna trials.

  • num_mc_batches (int | None) – Monte Carlo budget override. If None, use three batches per SNR for training tuning and 63 for validation and variance calibration.

  • batch_size (int | None) – Channels per evaluation batch. If None, use the canonical configuration value of four.

  • output_dir (str | pathlib.Path | None) – Output directory override for the selected stage.

  • algorithm_output_dir (str | pathlib.Path | None) – Directory containing the training study and paired-validation evidence used to select the canonical training recipe.

  • asset_root (str | pathlib.Path) – External root containing or receiving trained ReEsNet model assets.

  • training_data_manifest (str | pathlib.Path | None) – Manifest of the fixed training and validation data bank. This is required by the training and training-validation stages.

Returns:

An Optuna study for tuning stages or a dictionary containing paired-validation results for validation stages.
