Bench
================

This package contains benchmarks built with Sionna link-level simulations.

If you just want to look at a leaderboard, you can find it in the corresponding leaderboard page
of each benchmark, e.g., :doc:`MIMO-OFDM-CHEST <benchmarks/mimo_ofdm_chest/leaderboard>`.

To learn how you can run a benchmark locally and compare your own method, have a look at
the :doc:`Get Started <get_started>` page.

Sionna Bench currently contains the following benchmarks:

:doc:`benchmarks/mimo_ofdm_chest/index`
   A benchmark of MIMO-OFDM channel estimators.
