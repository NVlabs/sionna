======================
stop_system.sh
======================

SYNOPSIS
========

.. program:: stop_system.sh

.. code-block:: bash

    stop_system.sh

DESCRIPTION
===========

Stop all running Docker containers by executing ``docker compose down`` in the common configuration directory.

========

.. code-block:: bash

    stop_system.sh
