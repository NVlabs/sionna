Appendix C Closed-Form Solution for First-Order Diffraction

For first-order diffraction, the position of the diffraction point can be determined in closed form. Consider a source 𝐬, a target 𝐭, and an edge defined by its direction 𝐞^. For convenience, we assume the edge passes through the origin of the coordinate system, denoted by 𝐨.

According to Fermat’s principle, the diffraction point 𝐯 on the edge minimizes the total path length 𝐬→𝐯→𝐭. This corresponds to minimizing the function

ℒ⁢(x)=∥𝐬−𝐯∥2+∥𝐯−𝐭∥2 (183)

where

𝐯=x⁢𝐞^. (184)

As shown in [22], ℒ⁢(⋅) is strictly convex and thus has a unique minimizer.

We introduce the set of vectors (𝐮^1,𝐮^2,𝐮^3), where

𝐮^1 =𝐬−(𝐞^𝖳⁢𝐬)⁢𝐞^∥𝐬−(𝐞^𝖳⁢𝐬)⁢𝐞^∥2 (185)
𝐮^2 =𝐭−(𝐞^𝖳⁢𝐬)⁢𝐞^∥𝐭−(𝐞^𝖳⁢𝐬)⁢𝐞^∥2 (186)
𝐮^3 ={𝐮^1×𝐮^2 if ⁢𝐮^1×𝐮^2≠𝟎𝐞^ if ⁢𝐮^1×𝐮^2=𝟎. (187)

Note that 𝐮^3=±𝐞^, and that the source and the edge lie within the plane (𝐨,𝐮^1,𝐞^). A key observation is that rotating the target 𝐭 about the edge does not alter the path length. Specifically, let 𝐑𝐮^3⁢(ϕ) denote the rotation matrix for an angle ϕ around the edge (𝐨,𝐞^). Then,

ℒ⁢(x) =∥𝐬−𝐯∥2+∥𝐯−𝐭∥2 (188)
=∥𝐬−𝐯∥2+∥𝐯−𝐑𝐮^3⁢(ϕ)⁢𝐭⏟𝐭′∥2 (189)

holds for any ϕ∈ℝ. Especially, by rotating the target around the axis (𝐨,𝐮^3) by the angle

ϕ=π−arccos⁡(𝐮^1𝖳⁢𝐮^2), (191)

the rotated target 𝐭′ is placed in the same plane (𝐨,𝐮^1,𝐞^) as the source and the edge, but on the side opposite to the source with respect to the edge, as depicted in Figure 36. The rotation matrix 𝐑𝐮^3⁢(ϕ) is given by Rodrigues’ rotation formula [30].

Minimizing ℒ⁢(x) with the rotated target 𝐭′ is equivalent to 𝐬, 𝐯, and 𝐭′ being collinear, i.e.

(𝐯−𝐬)×𝐬𝐭′→ =𝟎 (192)
⇔x⁢(𝐞^×𝐬𝐭′→) =𝐬×𝐬𝐭′→ (193)

where 𝐬𝐭′→=𝐭′−𝐬. Since 𝐞^×𝐬𝐭′→ and 𝐬×𝐬𝐭′→ are parallel, the solution for x is

x=sign⁡([𝐞^×𝐬𝐭′→]𝖳⁢[𝐬×𝐬𝐭′→])⁢∥𝐬×𝐬𝐭′→∥2∥𝐞^×𝐬𝐭′→∥2. (194)
