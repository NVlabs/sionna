Bill of Materials#

This is a summary of the hardware components required to assemble the Sionna Research Kit. The exact choice of the RF components such as the cables is not critical and other components might work as well. You can find a more detailed list of components in the Ettus OAI reference architecture.

Computing Platforms#

Note

The NVIDIA DGX Spark is the recommended computing platform for the Sionna Research Kit. The DGX Spark provides hardware accelerated ray tracing for real-time channel emulation and a ConnectX-7 NIC.

The supported options for the computing platform are:

  • NVIDIA DGX Spark

  • NVIDIA Jetson AGX Thor

  • Legacy NVIDIA Jetson AGX Orin:

    • M.2 NVMe SSD for additional storage

    • An Ubuntu 22.04 or 24.04 host system is required to flash the Jetson Orin

An optional NVIDIA Jetson Orin Nano Super Developer Kit can be added as a second device to run the software-defined UE as described in the Software-defined End-to-End 5G Network tutorial. Note that, this setup requires an additional USRP.

RF Components#

  • Ettus USRP B210 Kit (other USRP models might work as well)

  • USB 3.0 cable (included)

  • SMA cables:

    • 8x SMA-SMA cable 50cm

    • 4x PigTail Cable SMA - MHF4, 15cm (required for the Quectel modem)

  • RF attenuators:

    • 1x 40dB attenuator BW-S40W2+ or 1x 20dB attenuator BW-S20W2+

  • RF splitters:

    • 1x 4-way splitter ZN4PD1-63HP-S+

    • 1x 2-way splitter ZN2PD2-50-S+

Note

The Ettus B205/206mini USRPs can be used as well, but they only support single antenna experiments, i.e., no MIMO experiments are possible.

User Equipment#

  • Quectel 5G RM520N-GL 5G Module

  • M.2 to USB adapter

  • Programmable SIM cards

  • SIM card programmer

  • Host PC with USB 3.0 port; ideally with Ubuntu 22.04 or 24.04

Optional Components#

  • RF shielding box for over-the-air testing (Faraday cage)

  • Additional antennas for over-the-air testing

  • Spectrum analyzer for signal analysis and debugging

  • Second Ettus USRP B210 for software-defined user equipment (see Software-defined End-to-End 5G Network)
