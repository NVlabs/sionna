Transport Block#

TBConfig(**kwargs)

Sets parameters related to the transport block encoding, as described in TS 38.214 [3GPPTS38214].

TBEncoder(target_tb_size, num_coded_bits, ...)

5G NR transport block (TB) encoder as defined in TS 38.214 [3GPPTS38214] and TS 38.211 [3GPPTS38211]

TBDecoder(encoder[, num_bp_iter, cn_update, ...])

5G NR transport block (TB) decoder as defined in TS 38.214 [3GPPTS38214].
