# Finding Template

## Title

Short, specific title.

## Severity

Critical | High | Medium | Low

## Component

Package, module, or workflow.

## Status

Confirmed | Suspected | Needs reproduction | Documentation gap | Test gap

## Evidence

- File and line references.
- Commands run.
- Minimal reproducer or reasoning chain.

## Expected Behavior

What should happen.

## Actual Behavior

What happens now.

## Impact

Who is affected, how often, and how bad the result is.

## Suggested Fix

Minimal fix and any broader cleanup worth considering.

## Implementation Improvement Opportunity

If this is an improvement rather than a correctness finding, describe the
current complexity or cost, expected benefit, API compatibility risk, numerical
risk, and validation needed.

## Test Or Documentation Additions

What should be added so this does not regress.

## Open Questions

Unresolved assumptions or decisions needed.
